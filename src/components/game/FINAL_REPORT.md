# Финальный отчёт /game

Интегрирован с `main` на `de7b51a`, включая объединённый PR #7, игру на главной странице и исправление первой отрисовки canvas.
Формулы, данные и `improve.ts` не изменены. Нет новых зависимостей.

## Контракт

Существующий `POST /api/explain {decisions}` по-прежнему возвращает
`{explanation, source}`. Все прежние проверки продолжают проходить.

Игра запрашивает совместимое расширение:

```json
{"decisions": [], "format": "report", "language": "ru"}
```

Здесь `decisions` должен быть валидным планом из пяти решений; пустой массив
в примере показывает только структуру и получает HTTP 400. Языки: `ru`, `kk`, `en`.
Неизвестный язык в режиме report также получает 400.

Ответ: `{format:"report", language, source, narrative, fallbackReason?}`.
`narrative` содержит строки `summary`, `quality`, `priority`, `reach`, `budget`,
`nextStep` и массивы строк `strengths`, `tradeoffs`. Это интерпретация AI,
отдельная от вычисленных фактов. JSON проверяется сервером и клиентом.
Числовые рейтинги, денежные суммы цифрами и технические коды в сгенерированном
тексте не принимаются: цифровые факты выводятся непосредственно из движка.
Это структурная проверка, не гарантия фактической точности произвольной прозы.

Сервер формирует полный baseline и scenario, все 50 показателей, критические
значения, последствия и синергии, распределение расходов по районам с отдельной
общегородской строкой и результат проверенной замены. Модели передаются
названия на выбранном языке. Она не рассчитывает числа и не назначает рейтинг.

Используются существующие `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` и соответствующие
`ANTHROPIC_MODEL` / `OPENAI_MODEL`; новые переменные не нужны. Ключи только на
сервере. Если провайдеры не настроены, недоступны или ответ не прошёл проверку,
возвращается `source:"offline-template", narrative:null` с причиной.
Интерфейс показывает локализованные факты с подписью «без AI» и повтор запроса.
Обычный расчёт и проверенная замена работают без ключей.

Для замены используется прежний `/api/improve`. Клиент повторно проверяет точную
пару measureId + districtId и пересчитывает предложение движком ещё до показа
кнопки применения. Применение снова пересчитывает план и аннулирует отчёт.
Смена языка отменяет запросы, сохраняет план и требует свежего AI-ответа.
Изменение плана отменяет запросы и удаляет результаты. Старые ответы
не проходят проверку версии. Повторные нажатия не запускают дубликаты.

Учебный масштаб денег остался предложенным: 1 единица модели = 10 млн ₸,
общий бюджет = 1 млрд ₸. Масштаб не утверждён пользователем; это видно в UI.
Коэффициент применяется исключительно при отображении стоимости, не к индексу.

## Демонстрация

1. `npm run dev`, открыть `/game`, выбрать язык.
2. «Загрузить пример» → «Получить оценку советника».
3. Индекс 52,56 → 56,54 (+3,99), стоимость 950 млн ₸, остаток 50 млн ₸.
4. В отчёте раскрыть районы: все исходные/итоговые показатели, расходы и критические значения.
5. Проверенная замена: поликлиника в Сарыарке → ЛРТ в Нуре.
   Индекс 57,21, стоимость 1 млрд ₸, остаток нулевой. Советник повышает общий
   индекс, а не оптимизирует справедливость; сравнение показывает потери и пользу районов.
6. Применить → старый отчёт закрывается. Снова запросить оценку.
   Отсутствие улучшения одной заменой не означает глобального оптимума.

## Проверки

```sh
npx tsc --noEmit
npx eslint .
npm run build
npm run verify
npm run verify:daniyal
npm run verify:improve
npm run verify:explain
npx tsx --test src/components/game/world.test.ts src/lib/finalReport.test.ts
python3 fixtures/daniyal/verify_http.py http://localhost:3000 --offline-explanation
```

Последний флаг только для сервера без AI-ключей. В среде разработки без npm/npx
запускались эквивалентные бинарники из node_modules/.bin с комплектным Node.js.
Свежая копия перед build имела известную ошибку LayoutProps из-за отсутствия
сгенерированных .next-типов; после build проверка типов проходит.

Проверено настоящим движком/обработчиком: контрольный пример, концентрация
расходов, небольшие улучшения в нескольких районах, оставшиеся критические
значения, негативный эффект, отсутствие улучшающей замены, совместимость старого
API, режим без ключей, три языка запроса, невалидные данные. Ответы OpenAI и
Anthropic, повреждённый JSON и сбои провайдера имитировались в тестах.

Дополнительно выполнен временный DOM-harness вне репозитория: открытие отчёта,
ошибка/повтор, смена языка во время запроса, запоздалый ответ, изменение плана,
повторные нажатия, отказ от подменённой рекомендации, применение и новый отчёт.
Полноценная визуальная проверка браузера на 375/1280 px недоступна: инструмент
не запускается с ошибкой sandbox TIOCSTI. Мобильная нижняя панель использует
существующий responsive dialog. Live LLM и качество перевода AI не проверены —
в рабочей копии нет настроенных ключей. Подготовленные ответы за live AI не выдаются.
